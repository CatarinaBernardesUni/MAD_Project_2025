# TimeToTeach - Online Classes App
The TimeToTeach application consists of a mobile app designed to manage online classes. The application provides a place for students, teachers and administrators to manage class scheduling, atendance, and user profile.  
- **Administrators** can create and manage classes, register teachers and students, and monitor atendance and system activity through a dashboard.
- **Teachers** can add classes, manage their subjects, and mark a endance directly from their mobile devices.
- **Students** can view their schedules, track a endance, and enroll in classes.
 
The main goal of the app is to offer a convenient, real-time, mobile solution for managing online classes without the complexity of web platforms or manual tracking. By integrating Firebase’s real-time database and 
authentica on services, the app ensures that data is synchronized instantly across all users.

## Notes:
To run this application, edit the constant firebaseConfig (your web app's Firebase configuration) inside the firebase_example.js and rename the file to firebase.js  
To upload profile images, upgrade your firebase plan to the **Blaze Plan**.  
This App was made as a part of the final project of Mobile App Development.
